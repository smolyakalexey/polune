# Polune

Мобильный веб‑MVP, который помогает быстро выбрать подходящую дату для небольшого бытового дела: стрижки, окрашивания, ухода, новой привычки или важного разговора.

Тестовая версия: https://blagopriyatny-den.smolyakalexey.chatgpt.site

## Что уже работает

- поиск по каталогу из 61 канонического дела и 553 формулировок;
- расчёт рекомендаций на ближайшие 14 дней;
- три лучших окна и полный календарь;
- объяснение результата без категоричных запретов;
- локальное сохранение выбранной даты;
- системный шаринг результата;
- стабильная ссылка, восстанавливающая выбранное дело и дату;
- минимальная анонимная аналитика без cookies и текста поиска;
- адаптивный интерфейс для телефона и компьютера.

## Локальный запуск на macOS

Понадобятся Node.js 22.13 или новее и npm.

```bash
npm install
npm run dev
```

После запуска открой адрес, который покажет терминал. Обычно это `http://localhost:5173`.

Для локальной проверки перед публикацией:

```bash
npm run check:local
```

## Основные файлы

- `app/page.tsx` — продуктовая логика и основной сценарий;
- `app/globals.css` — визуальная система и адаптивность;
- `app/layout.tsx` — метаданные и общий каркас;
- `docs/METHODOLOGY.md` — прозрачная формула, пороги и ограничения методики;
- `AGENTS.md` — постоянный контекст и правила для Codex;
- `.openai/hosting.json` — связь с опубликованной версией в Sites.

## Проверка

Линтер и production‑сборка запускаются одной командой:

```bash
npm run check:local
```
